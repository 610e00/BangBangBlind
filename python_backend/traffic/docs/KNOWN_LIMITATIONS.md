# 已知限制

- 遠距、斜角、遮光罩、低亮度與眩光場景有漏偵。
- 原CNN在部分新照片曾輸出高信心錯誤讀值，例如IMG_4753曾輸出88而與人工檢視不符。不可把confidence門檻或兩張連續讀值視為正確保證。
- 不確認穿越方向、不量測路寬與個人行走速度。15秒只是專題規則，不是可通行保證。
- 目前是手機與電腦連線架構，不是手機離線辨識。CPU速度依硬體與影像尺寸改變；2.5秒逾時會丟棄結果。
- 已通過使用者展示測試的是保留的影片展示版；這份統一API的相機樣板仍需由團隊在裝置上重跑驗收，不能把舊版驗收直接當成新包驗收。
- 不包含避障、人臉、導航、緊急聯絡或全域麥克風／音效管理器；只提供整合說明與userSpeaking接口。
